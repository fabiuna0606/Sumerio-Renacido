# FON-009 — Vocales largas

## Pregunta

¿Se distinguen vocales largas en el estándar?

## Opciones consideradas

1. Distinguir vocales largas de vocales breves
2. No distinguir vocales largas

## Decisión

Excluir.

## Puntuación

Puntaje = E − C + FL = 1 − 1 + 0 = 0 → excluir (se incluye si y solo si Puntaje > 0; un puntaje de 0 excluye).
